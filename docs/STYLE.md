# 样式规范

渲染层样式只有三层，从上到下改动成本递增：

```
@theme 变量（global.css）  →  Tailwind 工具类  →  pi- 语义类（@utility）
```

组件里**只写后两层的类名**，不写具体数值。唯一的数值出口是 `@theme`。

设计立场：**安静的中性外壳 + 一个记忆点**。Pi 的三色 logo 是界面里唯一的彩色强调，其余一切用中性灰阶、字重和留白建立层级；不做装饰性渐变、不做每块一样的卡片。

## 1. 刻度

| 类别 | 刻度 | 类名 | 备注 |
|---|---|---|---|
| 间距 | 2 / 4 / 8 / 16 px | `p-0.5` `p-1` `p-2` `p-4`（同理 px/py/gap/m/mt…） | ≥24px 的布局间距不纳入，用 `px-8`(32) 等标准步长 |
| 圆角 | 4 / 8 / 16 / 999 px | `rounded-sm` `rounded-md` `rounded-lg` `rounded-pill` | 999 只用于胶囊/头像 |
| 字号 | 12 / 14 px | `text-xs`（小字） `text-sm`（默认） | 角色见下一节 |
| 展示字号 | 28 px | `text-2xl` | 特例：仅问候语/品牌大字，全应用最多一处 |
| 字重 | 400 / 500 / 600 | `font-normal` `font-medium` `font-semibold` | 层级优先靠字重与颜色，不靠字号 |
| 宽高 | 不纳入刻度 | `w-[262px]`、`size-7` | 侧栏宽、图标尺寸属于布局，保持原值 |

刻度外的旧值按「**就近、平局偏小**」归入：6→4、7→8、13→12、14→16。新代码不得引入刻度外的值。

间距节奏：同一行内 4，组内元素 8，组与组之间 16 起。不要用 12 这种"半档"制造层级。

## 2. 字体与排版

| 角色 | 字号 | 行高 | 用法 |
|---|---|---|---|
| 正文 / 标题 / 按钮 / 菜单 / 输入 | `text-sm` 14 | 1.6（Markdown 1.85） | **默认字号**：消息、侧栏行、输入框、所有按钮与标题（含起始页大标题，靠字重与留白立层级） |
| 代码 / 小字 | `text-xs` 12 | 1.5（代码 1.7） | 代码块、路径、时间戳、kbd、徽标、加载与占位提示 |
| 展示大字（特例） | `text-2xl` 28 | 1.3 | 仅问候语/品牌大字，全应用最多出现一次 |

- 只有两套字体：`--font-ui`（系统 UI 栈）承载全部界面文字，`--font-mono` **只给代码/路径/等宽数据**，不用它做"技术感"标签。
- 层级顺序：字号 → 字重 → 颜色（`fg` → `muted` → `faint`）。缺省 400；强调用 500；600 只给标题和选中项。问候语是唯一的展示字号特例（`text-2xl`），其余标题仍靠字重与颜色立层级。
- 行宽 < 80 字符：对话区 `max-w-[820px]`，块预览 `max-w-[720px]`，对话框 440px。
- 对齐以左对齐为主；数字、时间、计数右对齐。不使用两端对齐。
- 禁止：全大写标签、每个标题上方的英文小眉标、句中单独加粗/变色一个词、句尾装饰性 `→`。

## 3. 颜色

全部是 `@theme` 里的语义变量，按角色使用，不按视觉深浅临时挑。

| 令牌 | 用途 | 对比度（panel 底） |
|---|---|---|
| `fg` | 正文 | 14.6:1 |
| `muted` | 次要文字、图标 | 3.36:1（仅 ≥12px 辅助信息） |
| `faint` | 极弱文字、禁用态 | 1.99:1（**不得承载信息**） |
| `link` | 链接、滑块渐变 | 4.3:1，链接需下划线 |
| `add` / `del` / `warn` | 新增 / 删除 / 警告 | add 4.1、warn 3.4，必须配图标或文字 |

- 底色：`canvas` 窗口底、`panel` 面板、`surface` 浮起白面、`sunken` 内凹区、`select` 选中行。
- 线：统一用 `edge`（分隔线与控件描边）。分隔线表达分组，不表达装饰；不要给每一块都加边框。
- 交互蒙层用透明黑两档 `tint`（4%，hover）/ `tint-strong`（6%，按压/常驻选中），不新造颜色。
- 阴影只给浮起来的层，按浮起高度四档：`shadow-hairline`（输入条）、`shadow-card`（主卡片/输入卡）、`shadow-pop`（菜单/提示/Toast）、`shadow-dialog`（对话框）。同层内容不要逐块加阴影。
- 主按钮与头像统一用 `fg`，滑块渐变用 `add → link`；新增颜色前先问能不能用现有中性色。

## 4. 结构层级

圆角与阴影表达层级，必须成对使用，不能全站一个半径：

| 层 | 圆角 | 阴影 | 例子 |
|---|---|---|---|
| 浮起层（对话框、菜单、toast） | 8–16 | 有 | `pi-card` + `shadow-dialog` |
| 面板 | 4–8 | 无或 `shadow-card` | 主卡片、`pi-panel` |
| 控件（按钮、输入、chip） | 4 | 无 | `pi-icon-btn`、`pi-input` |

- 不用"卡片墙"：内容靠节奏、分隔线和留白分组；只有真正独立的容器才给边框+底色。
- 结构标记只在内容本身有结构时使用（编号仅用于步骤/时间线）。
- 一个屏只允许一处强强调（彩色或被选中态最重的地方）。

## 5. 语义类

重复 3 次以上的类组合才提炼，统一 `pi-` 前缀，定义在 `global.css` 的 `@utility`：

| 类 | 用途 |
|---|---|
| `pi-panel` | 面板容器：8px 圆角 + `edge` 描边 + `panel` 底 |
| `pi-card` | 卡片/对话框：16px 圆角 + `edge` 描边 + `surface` 底 |
| `pi-icon-btn` | 28×28 图标按钮（含 hover 态） |
| `pi-menu` / `pi-menu-item` | 下拉容器（8px 圆角）/ 下拉项（28px 行高、项间距 2px、hover 4px 圆角） |
| `pi-page` | 内容页容器（820px 最大宽 + 32px 横向内边距） |
| `pi-input` | 单行输入框（含 placeholder / focus 描边） |
| `pi-btn` | 主按钮：`fg` 底 + 白字 + 14px 字号 |

语义类只装**结构与状态**，不装业务尺寸。业务差异继续用工具类叠加：`className="pi-card p-4 shadow-dialog"`。

## 6. 交互与动效

- hover：浅色底用 `bg-tint`，面板内行用 `bg-sunken`，选中行为 `bg-select`。
- focus：输入类用 `border-muted`；按钮与可点行必须有 `focus-visible` 可见焦点（2px 环，offset 2px），不允许只剩浏览器默认。
- disabled：`opacity-35`，并显式去掉 hover 底色（`disabled:hover:bg-transparent`）。
- 动效只回应人的动作（展开、确认、状态变化），时长 120–180ms、ease-out；不做逐段入场、不做常驻漂浮动画。
- 尊重 `prefers-reduced-motion`：新动效必须在该媒体查询里关闭。
- 可点区域 ≥28×28（`size-7`）；纯图标按钮必须有 `aria-label`。

## 7. 文案与术语

- 术语以 `GLOSSARY.md` 为准，同一对象全流程同名（当前侧栏用「任务」、术语表用「会话」，**需要统一**）。
- 句子式大小写，动词开头，说清发生什么：「新建会话」「已导出」，不用「提交」「确定」这类空动词。
- 动作名贯穿全流程：按钮「导出」→ 提示「已导出」。错误说明原因与下一步，不道歉、不模糊。
- 空状态是行动入口，不是心情文案。
- 界面文案只用中文与必要英文术语；不用中英混排出"设计感"。

## 8. 新增样式的流程

1. 先在刻度表里找现成值；没有再谈新增。
2. 需要新颜色/新阴影：加 `@theme` 变量，命名按角色（`--color-<role>`、`--shadow-<role>`），并在本文件补一行说明。
3. 同一组合出现第 3 次：提 `pi-` 类。
4. 用「组件预览」页验证：改令牌实时看效果，「复制为 CSS」把最终值贴回 `@theme`。预览面板的改动只存 localStorage，不算定稿。
5. 跑 `npm run typecheck`，截图确认视觉无回归（含焦点态、窄窗口）。

## 9. 反例

```tsx
// ✗ 任意值 + 卡片墙 + 同阴影
<div className="rounded-[7px] text-[13px] p-[6px] bg-[#f0f0f0] shadow-[0_2px_8px_rgba(0,0,0,.2)]" />

// ✓ 令牌 + 语义类
<div className="pi-card p-4 shadow-dialog" />
```

**避免的默认化写法**（会读起来像模板生成）：每块内容同一个圆角同一个阴影、标题上方的全大写小标签、一句里单独变色一个词、链接后加装饰箭头、给所有区块配渐变色块。

## 10. 现状待修

按本规范核对当前实现，以下几处不一致，改样式时顺手修：

- 按钮/可点行没有 `focus-visible` 焦点环（键盘用户看不见焦点）。
- `muted` 3.36:1、`faint` 1.99:1 都低于正文 4.5:1；`faint` 目前承载了会话时间、占位符等信息。
- `add`、`warn`、`link` 在 panel 底上略低于 4.5:1，需加深或只用于大字/配图标。
- 侧栏「任务」与术语表的「会话」不一致。
