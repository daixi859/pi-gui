# 0009 设计令牌与刻度归一

## 决定

样式分三层，全在 `src/renderer/src/styles/global.css`：

1. `@theme` 里的 CSS 变量：颜色（含透明黑蒙层、组件专用色）、字号、圆角、阴影、Tailwind 的 `--spacing`。
2. Tailwind 生成的原生工具类（`bg-panel`、`text-xs`、`rounded-md`、`p-2`、`shadow-card`）。
3. `@utility` 定义的 `pi-` 语义类（`pi-card`、`pi-panel`、`pi-icon-btn`、`pi-menu`、`pi-menu-item`、`pi-page`、`pi-input`、`pi-btn`），只收重复 3 次以上的组合。

刻度：间距 2/4/8/16（Tailwind 的 `p-0.5/1/2/4`）、圆角 4/8/16、字号 12/14（正文/标题 14，代码与小字 12），另有 28px 展示字号特例（`text-2xl`）只用于问候/品牌大字。刻度外的取值按「就近、平局偏小」归入（6→4、7→8、13→12）。≥24px 的布局间距、宽度、高度不纳入距离。

组件预览页的「外观令牌」面板把改动写到 `:root` 内联变量并记在 localStorage，可「复制为 CSS」手动回填，**不写文件**。

## 为什么

- 统一修改：改一行 `@theme` 就能调整全局圆角/字号/间距，不用全局搜索任意值。
- 视觉一致：侧栏、卡片、弹窗此前混用 2/3/4/5/6/7/10/14px 圆角与 10.5–14px 字号，肉眼难辨但难维护。
- 预览页需要一个稳定的调节口，运行时变量是最小实现：无需 IPC、无需改源码，刷新可恢复。

## 代价

- 归一带来可见变化：圆角 6→4、7→8、14→16；字号 13→12（约 16 处），正文整体略小。
- 刻度减小了表达力，个别对齐（如 22/30px 缩进）留在刻度外，仍需任意值或布局类。
- `pi-` 语义类与 Tailwind 工具类混用，新组件要判断「是不是重复组合」，增加一点决策成本。

## 备选与放弃原因

- 只用 CSS 变量、不做语义类：重复的长 className 仍然难读。
- 用 `@apply` 建 BEM 式组件类：与 Tailwind 用法冲突，且变体（hover/disabled）表达力差。
- 令牌面板直接改 `global.css`：渲染层无写权限，且不应在运行时改源码。
